## 👋 About

I'm **Dys** — a self-taught developer from Florida building **extensions, integrations, and infrastructure for AI coding agents**: language-server integrations, MCP servers, LLM API monitors, and agent benchmarks.

I care about open source, clean developer experience, and shipping tools that make other developers faster. Off the keyboard: cyber security, 3D modeling, graphic design, and gaming.
