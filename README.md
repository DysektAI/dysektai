## 👋 About Me

I'm **Dys** — a self-taught developer from Florida. I started out in full-stack web development and ended up deep in the AI tooling rabbit hole. Today I build **extensions, integrations, and infrastructure around AI coding agents** — language-server integrations, MCP servers, LLM API monitors, and agent benchmarks.

I care about open source, clean developer experience, and shipping tools that make other developers faster. Off the keyboard: cyber security, 3D modeling, graphic design, and gaming.

## 🚀 Featured Projects

| Project | What it does | Built with |
|:---|:---|:---|
| [**pi-extensions**](https://github.com/DysektAI/pi-extensions) | Public-safe extensions for the Pi coding agent — config menu, tasks, search, LSP, goal loops, and UX helpers | `TypeScript` |
| [**pi-lsp**](https://github.com/DysektAI/pi-lsp) | Managed, cross-platform language-server integration for Pi, with an interactive control panel and first-class C#/.NET support | `TypeScript` `Vitest` |
| [**ai-api-monitor**](https://github.com/DysektAI/ai-api-monitor) | Self-contained, zero-dependency Node.js monitor for AI API endpoints — availability, latency, and uptime across OpenAI-compatible and Anthropic providers | `Node.js` `Zero-dep` |
| [**agentbattler-bench**](https://github.com/DysektAI/agentbattler-bench) | Public, reproducible GitHub Actions benchmark comparing AI coding-agent harnesses through constrained chess agents | `JavaScript` `GH Actions` |

Also hacking on a [fork of the Pi AI agent toolkit](https://github.com/DysektAI/pi-fork) (coding-agent CLI, unified LLM API, TUI & web UI libraries) and a [Discord MCP server](https://github.com/DysektAI/discord-mcp).
